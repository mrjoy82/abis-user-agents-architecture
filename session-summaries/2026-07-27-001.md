## 2. Key Decisions Locked

### Architecture
- **Container tech:** systemd-nspawn (POC on Pi), Docker (Phase 2 on Mac Mini M5)
- **Container type:** Progressive — same image, permissions JSON controls available tools
- **Communication:** WebSocket streaming via Cloudflare Tunnel
- **Agent:** ATA (ABIS Tutor Agent) — FastAPI + WebSocket server using Hermes DNA
- **Portal:** Cloudflare Pages frontend + Pi backend (7582 for API, 7583 for orchestrator)
- **Storage:** pi-nas via NFS for persistent user data (5GB per kid)
- **Resource limits:** 1GB RAM, 25% CPU, 5GB disk per container

### Safety
- **Phase 1:** Orchestrator-level keyword scanning on ALL traffic (both directions)
- **Phase 2:** Intent classification + human review queue
- **Admin controls:** Approve/reject users, set permissions per user, pause containers, view alerts

### Permissions (Progressive Unlock)
| Tool | Ages 10-12 | Ages 15+ |
|------|-----------|----------|
| Chat | ✓ | ✓ |
| File management | ✓ | ✓ |
| Web search | ✗ | ✓ (Phase 2) |
| Code execution | ✗ | ✓ (Phase 2) |
| Terminal commands | ✗ | ✓ (Phase 2) |
| Browser automation | ✗ | ✓ (Phase 2) |
| Image generation | ✗ | ✓ (Phase 2) |
| Cron jobs | ✗ | ✓ (Phase 2) |
| OpenClaw bridge | ✗ | ✓ (Phase 2) |

### Timeline
- **POC:** 1-2 week sprint, iterative, no hard deadline
- **Max concurrent:** 8 kids on Pi 5 (16GB RAM)
